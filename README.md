# Vocab Hunter — เกมล่าคำศัพท์ (Vite + PWA + GitHub Pages)

## โครงสร้างโปรเจกต์
```
VOCAB-HUNTER/
├─ index.html            หน้าเกม
├─ package.json          คำสั่ง dev / build / preview / deploy
├─ vite.config.js        ตั้งค่า base (ชื่อ repo) + PWA (ไอคอน ชื่อแอป ออฟไลน์)
├─ .gitignore            ไม่ให้ node_modules / dist ขึ้น GitHub
└─ public/               ทุกอย่างในนี้ถูกคัดลอกไป dist/ ตามเดิม
   ├─ favicon.ico            ไอคอนแท็บเบราว์เซอร์
   ├─ apple-touch-icon.png   ไอคอนหน้าจอโฮม iPhone/iPad (180×180)
   ├─ pwa-192x192.png        ไอคอนแอป Android
   ├─ pwa-512x512.png        ไอคอนแอปขนาดใหญ่ / หน้า splash
   ├─ maskable-512x512.png   ไอคอน Android ที่ถูกตัดเป็นวงกลม/สี่เหลี่ยมมน
   ├─ js/  css/  data/       โค้ดเกม
   └─ assets/                ภาพแผนที่ + logo.png (ฉากเปิดเกม)
```

## Deploy ครั้งแรก
1. สร้าง repo ชื่อ **VOCAB-HUNTER** บน GitHub (ว่าง ๆ ไม่ต้องติ๊ก README)
2. แก้ `homepage` ใน `package.json` ใส่ชื่อผู้ใช้ GitHub ของตัวเอง
3. เปิด Terminal ในโฟลเดอร์นี้:
```
npm install
npm run build
npm run preview        (ลองเปิดดูก่อน แล้วกด Ctrl+C เพื่อปิด)
git init
git remote add origin https://github.com/ชื่อผู้ใช้/VOCAB-HUNTER.git
git branch -M main
git add .
git commit -m "first commit"
git push -u origin main
npm run deploy
```
4. บน GitHub: **Settings → Pages → Branch: `gh-pages` / `(root)` → Save** (ทำครั้งเดียว)
5. รอ 1–3 นาที เปิด `https://ชื่อผู้ใช้.github.io/VOCAB-HUNTER/`

> ถ้า push แล้วขึ้นหน้าต่างให้ใส่รหัส ให้ล็อกอิน GitHub ในหน้าต่างนั้น ถ้าเคยล็อกอินบัญชีอื่นไว้ ให้ลบที่ **Windows → Credential Manager → Windows Credentials → git:https://github.com**

## อัปเดตเกมครั้งต่อไป
```
npm run build
git add .
git commit -m "อธิบายว่าแก้อะไร"
git push
npm run deploy
```
แอปที่ติดตั้งในมือถือจะอัปเดตเองเมื่อเปิดครั้งถัดไป (ถ้ายังเห็นของเก่า ปิดแอปแล้วเปิดใหม่อีกรอบ)

## ติดตั้งลงมือถือ
- **iPhone:** เปิดลิงก์ใน **Safari** → ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"
- **Android:** เปิดใน **Chrome** → เมนู ⋮ → "ติดตั้งแอป"

## ปัญหาที่พบบ่อย
- **หน้าขาว / ไฟล์ 404:** `base` ใน `vite.config.js` ต้องเป็น `/VOCAB-HUNTER/` ตรงกับชื่อ repo ทุกตัวอักษร
- **แก้ไฟล์เกมตรงไหน:** แก้ใน `public/js`, `public/css`, `public/data` (ไม่ใช่ใน `dist/` เพราะ dist ถูกสร้างใหม่ทุกครั้งที่ build)
- **เปลี่ยนไอคอน:** วางไฟล์ใหม่ทับใน `public/` ชื่อเดิม ขนาดเดิม

## รายละเอียดเกม (เดิม) — Game UI Edition

เว็บเกมฝึกคำศัพท์ภาษาอังกฤษแบบ Hidden Object พัฒนาด้วย HTML, CSS และ JavaScript แบบไม่ต้องใช้ Backend

## วิธีเปิดโปรเจกต์
1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ `vocab-hunter-game-v4` ใน VS Code
3. เปิด `index.html` ผ่านส่วนขยาย Live Server (แนะนำ) หรือเว็บเซิร์ฟเวอร์ภายในเครื่อง
4. เริ่มเล่นจากหน้า Main Menu

## สิ่งที่ปรับปรุงในเวอร์ชันนี้
- เพิ่มหน้า Main Menu พร้อมปุ่มเล่นต่อ เลือกด่าน Daily Challenge และ Endless Mode
- เพิ่มหน้าเลือกด่าน โดยดึงข้อมูลจาก `data/levels.js` อัตโนมัติ
- เพิ่มหน้า Player Stats และ Achievement
- เพิ่มหน้า How to Play
- เพิ่มหน้า Settings สำหรับเปิด/ปิดเสียงเอฟเฟกต์ และลด Motion
- ปรับ HUD, Sidebar, การ์ดภารกิจ, ปุ่ม และหน้าต่าง Modal ให้เป็น Game UI มากขึ้น
- เพิ่ม Responsive layout สำหรับหน้าเมนูและหน้าจอเกมบนจอขนาดเล็ก
- ยังคงใช้ระบบเดิม: สุ่มภารกิจ Endless, ป้องกันชุดภารกิจซ้ำติดกัน, Daily Challenge, Review Mistakes, Radar Hint, Speech Recognition, คะแนน, Streak, Achievement และการสร้าง Hitbox

## อัปเดต v9 — แผนที่ภาพวาดใหม่ 5 ฉาก
- เปลี่ยนแผนที่เป็นภาพวาดแนวหนังสือหาของ (ไฟล์ `assets/*.webp`) 5 ฉาก: สวนสนุก, เมือง, ตลาดนัด, ชายหาด และ **โรงเรียน (ด่านใหม่)**
- **ฉากละ 40 เป้าหมาย** (คำศัพท์ ~23 + ประโยค ~17) ทุกคำมีอยู่ในภาพจริง คำที่ไม่มีในภาพถูกเปลี่ยนเป็นของที่มีในภาพแทน
- **รอบละ 10 เป้าหมาย** เกมจะสุ่มคำที่ยังไม่เคยเก็บก่อน เล่นราว 4–5 รอบก็ครบ 40 คำ
- **ตัวนับ "เก็บคำในฉากนี้แล้ว x/40"** ในแถบรายการคำ และในหน้าเลือกด่าน
- ของที่มีหลายจุดในภาพ (เช่น ร่มชายหาด นกนางนวล หัวดับเพลิง) แตะจุดไหนก็นับ (`altHitboxes`)
- เป้าหมายที่กรอบทับกัน (เช่น คำว่า Magician กับประโยคเรื่องนักมายากล) จะไม่ถูกสุ่มมาในรอบเดียวกัน
- ไฟล์ SVG เดิมยังอยู่ใน `assets/` แต่ไม่ได้ใช้แล้ว

### เปลี่ยนเป็นภาพความละเอียดสูงกว่า
พิกัด hitbox อิงภาพขนาด 1536×1024 ถ้าขยายภาพด้วย Upscayl (เช่น 2× หรือ 4×) แล้วเอาไฟล์มาแทนชื่อเดิมได้เลย
**ไม่ต้องแก้พิกัด** เพราะเกมแสดงภาพที่ขนาด 1536×1024 เสมอ ภาพแค่คมขึ้นเวลาซูม (สัดส่วนภาพต้องเป็น 3:2 เท่าเดิม)

## อัปเดต v8 — Candy Arcade + ลานฝึกศัพท์
- **ลานฝึกศัพท์ (มินิเกม)** เข้าได้จากเมนูหลัก ปุ่ม 🎮 บนแถบด้านบน และหน้าจบรอบ
  - 5 โหมด: ผสมทุกแบบ, ฟังแล้วตอบ, ไทย→อังกฤษ, เรียงตัวอักษร/เรียงประโยค, เติมคำ + โหมด "คำที่เคยผิด"
  - 10 ข้อต่อรอบ หัวใจ 3 ดวง คอมโบ ให้ดาว 1–3 และบันทึกสถิติสูงสุด
  - คำที่ตอบผิดถูกเก็บไว้ฝึกซ้ำ ตอบถูกแล้วจะหายจากรายการ
  - คีย์บอร์ด: กด 1–4 เลือกคำตอบ, Enter ไปข้อถัดไป
- **คลังคำศัพท์ 160 รายการ** (ฉากละ 40 คำ/ประโยค ระดับ A1–B1) ใน `data/vocab-bank.js` พร้อมคำอ่านไทย คำแปล และประโยคตัวอย่าง
- **หน้าเล่นแผนที่สนุกขึ้น**: คอนเฟตตีตอนหาเจอ ตัวเลขดาวลอย ระบบคอมโบ (+10% ต่อขั้น สูงสุด +50%) หน้าจบรอบให้ดาว 1–3 พร้อมสถิติ เวลา/แตะผิด/เรดาร์/คอมโบ และรายการคำที่เก็บได้
- **มือถือ**: แถบด้านบนเหลือแถวเดียว แผนที่ใหญ่ขึ้น ตัวเลขเรดาร์โทเคนแสดงบนปุ่มเรดาร์
- **ปุ่ม "สร้างด่าน" ซ่อนจากผู้เล่น** เปิดได้ที่ ตั้งค่า → โหมดผู้สร้างด่าน
- ธีมใหม่อยู่ในไฟล์แยก `css/fun.css` (ถ้าอยากกลับไปธีมเดิม ลบบรรทัด `<link ... fun.css>` ใน index.html)

### เมื่อได้ภาพแผนที่ใหม่
คำใหม่ใน `vocab-bank.js` ยังไม่มี hitbox จึงเล่นได้แค่ในลานฝึกศัพท์ เมื่อได้ภาพใหม่ ให้เพิ่ม quest ใน `data/levels.js`
โดยใช้ **id เดียวกับในคลัง** (เช่น `q19` = Balloon) พร้อม hitbox แล้วคำนั้นจะไปอยู่บนแผนที่ด้วย

## โครงสร้าง
- `index.html` — หน้าจอเกมและหน้าต่างต่าง ๆ
- `css/style.css` — รูปแบบ UI และ Responsive layout
- `js/app.js` — ควบคุมเกมและเมนู
- `js/mapEngine.js` — การซูม/ลากแผนที่และ Hitbox
- `js/speech.js` — ระบบฟังและประเมินการออกเสียง
- `js/arcade.js` — ลานฝึกศัพท์ (มินิเกม)
- `js/fx.js` — เอฟเฟกต์คอนเฟตตี/ตัวเลขลอย
- `data/vocab-bank.js` — คลังคำศัพท์ 160 รายการ
- `css/fun.css` — ธีม Candy Arcade (โหลดต่อจาก style.css)
- `data/levels.js` / `data/levels.json` — ข้อมูลด่านและภารกิจ
- `assets/` — ภาพแผนที่ SVG ปัจจุบัน

## บันทึกข้อมูล
ข้อมูลความคืบหน้าเกมเก็บใน `localStorage` ของ Browser เครื่องนั้น ๆ การล้างข้อมูลเว็บไซต์อาจทำให้ความคืบหน้าหายได้

## หมายเหตุ
- ภาพแผนที่ทั้ง 4 ฉากยังเป็นภาพ SVG เวอร์ชันเดิมใน ZIP ต้นทาง การปรับภาพ Hidden Object แบบวาดมือที่มีรายละเอียดสูงเป็นงานแยก และไม่เปลี่ยนในรอบ UI นี้ เพื่อไม่ให้พิกัด Hitbox เดิมคลาดเคลื่อน
- การใช้ไมโครโฟนควรเปิดผ่าน `localhost` (เช่น Live Server) หรือ HTTPS และอนุญาตสิทธิ์ไมโครโฟนใน Browser
- ฟอนต์ออนไลน์อาจ fallback เป็นฟอนต์ในเครื่องหากไม่มีอินเทอร์เน็ต
