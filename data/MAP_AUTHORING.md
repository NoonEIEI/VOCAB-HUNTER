# เพิ่มแผนที่และคำศัพท์ใหม่ (Map & Vocabulary Database)

เกมอ่านข้อมูลแผนที่จาก `data/levels.js` ผ่าน `window.LEVELS_DATA` โดยแต่ละแผนที่เป็น object หนึ่งชุด ไม่ต้องแก้ `app.js` หรือ `mapEngine.js` เมื่อเพิ่มแผนที่ใหม่

## โครงสร้างข้อมูลแผนที่

```js
{
  mapId: "garden_01",                 // ต้องไม่ซ้ำกับแผนที่อื่น
  title: "Level 5: Secret Garden",
  titleTH: "ด่าน 5: สวนลับ",
  mapImage: "./assets/secret-garden.svg",
  mapWidth: 2800,
  mapHeight: 1800,
  quests: [
    {
      id: "garden_flower_01",         // ต้องไม่ซ้ำภายในแผนที่
      type: "word",                   // word หรือ sentence
      targetText: "Sunflower",
      phonetic: "ซัน-ฟลาว-เวอร์",
      meaningTH: "ดอกทานตะวัน",
      hitbox: { x: 420, y: 350, width: 90, height: 100 }
    }
  ]
}
```

## ขั้นตอนเพิ่มแผนที่

1. วาดหรือเตรียมภาพแผนที่แบบ 2D hand-drawn ที่มีรายละเอียดเยอะ ขนาดแนะนำ 2800 × 1800 px (หรือใช้สัดส่วนเดียวกัน)
2. วางไฟล์ไว้ใน `assets/` และตั้งชื่อไฟล์ภาษาอังกฤษ เช่น `secret-garden.svg`
3. เพิ่ม object ของแผนที่ใน array `window.LEVELS_DATA` ใน `data/levels.js`
4. กำหนด `mapWidth` และ `mapHeight` ให้ตรงกับภาพจริง
5. เพิ่ม quest อย่างน้อย 12 จุด พร้อม hitbox ที่ครอบวัตถุจริง
6. เปิดเกมแล้วทดสอบทุก hitbox ด้วยการซูมและคลิกทั้งเมาส์และจอสัมผัส

## ข้อควรระวัง

- `mapId` และ `quest.id` ต้องไม่ซ้ำ เพราะใช้บันทึกประวัติการสุ่มและคำที่ต้องทบทวนใน Local Storage
- ห้ามย้ายวัตถุในภาพโดยไม่ปรับ hitbox ให้ตรงกัน
- `hitbox` ใช้พิกัดภาพต้นฉบับ ไม่ใช่พิกัดหน้าจอ
- คำศัพท์ที่เคยตอบผิดจะถูกเก็บใน `reviewQueue` และถูกนำกลับมาฝึกจนตอบผ่าน
- เพิ่มแผนที่ใหม่ได้โดยเพิ่มข้อมูลและภาพเท่านั้น ระบบสุ่มแผนที่/ภารกิจใช้ข้อมูลจาก array นี้อัตโนมัติ

## คลังคำศัพท์ (vocab-bank.js)

`data/vocab-bank.js` เก็บคำทั้งหมดของแต่ละฉาก (ฉากละ 40) ใช้ในลานฝึกศัพท์ได้ทันทีโดยไม่ต้องมี hitbox
ถ้าอยากให้คำในคลังไปอยู่บนแผนที่ ให้เพิ่ม quest ใน `levels.js` โดยใช้ `id` เดียวกับในคลัง
แล้วใส่ `hitbox` ระบบจะดึงระดับคำ (A1/A2/B1) และประโยคตัวอย่างจากคลังมาใช้ให้อัตโนมัติ

## แผนที่ภาพวาด (v9)
- พิกัดทั้งหมดอิงภาพ 1536×1024 (`mapWidth`/`mapHeight` ใน levels.js)
- `altHitboxes`: รายการกรอบเพิ่มเติม สำหรับของที่มีหลายจุดในภาพ แตะกรอบไหนก็นับว่าเจอ
- id ของเป้าหมายในแต่ละฉาก ใช้ตรงกับ `vocab-bank.js` (ฉากโรงเรียนใช้ `s1`–`s40`)
